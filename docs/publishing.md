# Publishing and distribution

This repository is distributed as source/configuration at <https://github.com/clankercode/lsp-openplanet-helix>. Clone a reviewed commit or GitHub source archive and run the documented installer. It is deliberately not a competing npm package: install the server's official `openplanet-lsp` package separately.

Helix 25.07.1 has built-in language configuration plus user/project overrides, not a VS Code-style extension marketplace. No paid account or registry enrollment is needed to use this integration. **No registry PR has been submitted.** An upstream contribution adding AngelScript to [helix-editor/helix](https://github.com/helix-editor/helix) would be a separate maintainers-reviewed change, not a prerequisite for this configuration repo. It would need grammar licensing, pinned grammar, query compatibility and default LSP naming discussed with those maintainers; do not claim it exists.

Repository metadata: public, description "Openplanet AngelScript language server and syntax integration for Helix", topics `openplanet`, `trackmania`, `angelscript`, `lsp`, `language-server`, `helix`. Homepage points to this repository's rendered README. CI tests are under `.github/workflows/test.yml` and require only Python 3.11. No registry credentials or CI secrets are needed.

Maintainer release checklist:

1. Run `python3 -m unittest discover -s tests -v`.
2. Run the opt-in real Helix smoke test described in `verification.md`, including grammar build, manifest coexistence and diagnostics clearing. Record versions and actual limits.
3. If updating the grammar pin, copy the matching query and full license and rerun the live test. Review ABI compatibility with the minimum supported Helix.
4. Inspect the screenshot as actual editor output; never generate a lookalike.
5. Review changes, commit and push `main`. Optionally tag a reviewed version and use GitHub's autogenerated source archives; no custom build artifact is required.

GitHub Pages is unnecessary: the useful public documentation is the rendered README plus `docs/` in the repository. No Pages deployment or registry publication is claimed.
